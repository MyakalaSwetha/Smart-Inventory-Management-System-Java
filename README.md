# Smart Inventory & Billing Management System (Java + Oracle DB)

An Enterprise-grade console application designed to handle store inventory, automate real-time billing, and synchronize live product stocks directly with Oracle Database using JDBC.

## 🚀 Key Features
- **Database Persistence**: Real-time CRUD operations synced directly with Oracle Database.
- **Dynamic Stock Control**: Automatic stock updates in the database upon item purchase/billing.
- **PreparedStatement Integration**: Secure SQL execution preventing SQL Injection attacks.
- **Auto Invoice Engine**: Instant bill total calculation and real-time stock reduction.

## 🛠 Tech Stack
- **Language**: Java (JDK 17+)
- **Database**: Oracle Database 23c / 26ai
- **Driver**: Oracle JDBC Driver (`ojdbc17.jar`)
- **API**: Java Database Connectivity (JDBC - Statement, PreparedStatement, ResultSet)
